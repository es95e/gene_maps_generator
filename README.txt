Hello, this script generates comparative gene maps of a genomic locus across multiple species, showing gene order, orientation, annotation and amino acid identity between homologous genes. A reference species is displayed on top and the other species are ordered according to their phylogenetic position.
The script was designed and progressively improved during the analyses of the following publications:
1) Turroni et al. 2025, Microbial Biotechnology, "Quorum Sensing via Autoinducer-2 Promotes Colonisation and Host Adaptation in B. bifidum PRL2010".
2) Lugli et al. 2025, Microbiome Research Reports, "Unveiling the genetic landscape and motility-associated functions of Type IV pili in the Bifidobacterium genus".
3) Selleri et al. 2026, Microbiome Research Reports, "Genome-scale insights into the metabolic landscape and evolutionary development of Bifidobacterium bifidum".

This is a small utility script. It was built to produce clean, repitable, quickly-editable maps for specific loci, and it is NOT meant to replace established, peer-reviewed tools (see "LIMITATIONS AND ALTERNATIVES").

This repository also contain the scirpt extract_position_gbk.py, a script developed for rapidly creation of a file with the information needed for the creation of the genes maps ( CDS name, start, end, verse and contig). 
This script requires a gene_list.txt file containing the list of locus tags for which you wish to extract features. Additionally, you must provide the corresponding `.gbk` file (generated by PROKKA, BAKTA, or NCBI), renamed to match the locus tag assigned to the genome (please refer to the example files provided in the subfolder).

FEATURES:
- Gene maps drawn to scale (arrow length proportional to gene length, real intergenic distances), with the reference species on top and the other species ordered by a user-defined phylogenetic rank.
- Contig interruptions and long gene distances are shown directly in the final figure: when two neighbouring genes lie on different contigs, or when their distance exceeds X bp (X is adjustable, 10000 bp by default), the gap is shortened and marked with a double slash. The interruption therefore stays visible in the image, and a fragmented assembly or a distant gene does not stretch the figure and make it unreadable.
- Any gene can be highlighted (colour and edge adjustable) to follow it across species.
- Two colouring modes, selectable at each run: by annotation (functional category, automatic tab20 palette) or by gene_name (user-defined colour table, so that the same gene has the same colour in all figures). The same table can thus be drawn both ways without editing it.
- The homology between genes is defined by the user (same gene_name) and the identity values shown in the links are read from the table, so they can come from any source (BLASTp, DIAMOND, EMBOSS, etc.).
- Since nothing is aligned or recalculated by the script, producing a figure is fast, provided that the identity values (e.g. BLASTp/DIAMOND) have been calculated beforehand and added to the table.
- It also works to simply DRAW loci without comparing them: if the genes of different species have different gene_name values (or an empty gene_name), no gray link is generated, and identity/value_identity can be left empty. Each species line is then an independent, to-scale representation of its locus.
- Output in PNG, SVG or PDF, with editable text in SVG/PDF.

REQUIREMENTS:
A) A Python environment with the following packages: pandas, numpy, matplotlib.
B) Font: "Times New Roman" is used if installed; otherwise the script automatically falls back to Liberation Serif, Nimbus Roman, TeX Gyre Termes, FreeSerif or DejaVu Serif (always available). A different preferred font can be set with --font.
C) The input files described below, located in the working directory. Example files are provided in the repository.

INPUT FILES:
1) example_locus_info.csv (mandatory) -> One row per gene of the locus, for all species. Columns:
	- species: species name (italic label on the left of the map).
	- strain: strain name (written under the species name).
	- gene_number: unique gene identifier (locus tag).
	- annotation: gene annotation (used for coloring when gene_name coloring is not selected).
	- phy: numeric rank defining the order of the species in the map (after the reference species).
	- order: "F" if the locus is drawn as in the genome, "R" if it must be flipped, so that all loci are shown in the same orientation. For "R" species the locus is mirrored AND the strand of every gene is inverted automatically, so "verse" must contain the real strand in the genome. If you already inverted "verse" in the CSV for the "R" species, use --no-flip-strand.
	- start, end: genomic coordinates of the gene.
	- verse: strand of the gene ("+" or "-").
	- identity: value between 0 and 1 defining the transparency of the gray link between homologous genes. Values between 1 and 100 are interpreted as percentages and divided by 100 (a warning is shown); values outside 0-100 raise an error.
	- value_identity: identity value (%) reported in the middle of the link (can be empty).
	- gene_name: gene name. Genes with the same name in adjacent species are linked (see HOW IT WORKS for paralogs).
	- gene_at_-1, gene_target, gene_at_+1: gene_number of the gene itself (gene_target) and of its neighbours. Any gene_at_* column is used to define the genes of the locus.
	
2) example_locus_contig.csv (mandatory) -> Information on contig continuity, one row per gene. Columns:
	- species, target (gene_number);
	- continuity: if "NO", a contig break is present before the gene (in genomic orientation);
	- same_contig -3 ... +3: whether the neighbouring genes lie on the same contig. A "NO" value is interpreted as a contig interruption (any other value, e.g. "YES", means continuity).
	A contig break between two neighbouring genes is reported (one single criterion, used both for the shortened spacing and for the double slash) if: continuity of the downstream gene is "NO", or same_contig -1 of the downstream gene is "NO", or same_contig +1 of the upstream gene is "NO". Columns at distance +-2 and +-3 are not used for the drawing. A break is also drawn when the intergenic distance exceeds the threshold.
	
3) Genes_color_set.csv (optional) -> Table with the columns gene_name and color_code (hex code), used only when genes are colored by gene name. Numeric gene names (placeholders for flanking/unrelated genes) should be assigned the black color (#000000) and are not shown in the legend. Entries of the table that are not present in the drawn loci are not shown in the legend either.

HOW IT WORKS:
The script (draw_all_species_loci function) draws one line per species. For each species it:
    1) Selects the genes of the locus and orders them according to the "order" column.
    2) Draws each gene as an arrow, proportional to its length and oriented according to the strand, keeping the real intergenic distances. Distances above the threshold (10000 bp by default) or contig interruptions are shortened and marked with a double slash.
    3) Links homologous genes (same gene_name) between strictly adjacent species with gray polygons, with transparency proportional to the "identity" column, and reports the "value_identity" value in the middle. Links are never drawn within the same species. If a gene_name appears more than once in a species (paralogs), the n-th copy (in drawing order, left to right) is linked to the n-th copy in the next species; extra copies are left unlinked. If a gene is absent in the adjacent species no link is drawn, unless --link-skip-missing is used (the link then goes to the next species that carries the gene).
    4) Adds species names, strains, a 1000 bp scale bar and a legend.

USAGE:
    python genetic_maps.py
Without arguments the script interactively asks:
    - whether to highlight a specific gene (and its gene_name);
    - whether to color the genes by gene_name (colors loaded from the color file) instead of annotation (colors automatically assigned from the tab20 palette).
For use in pipelines, everything can be given on the command line (python genetic_maps.py --help):
    --info, --contig        input tables (defaults: example_locus_info.csv, example_locus_contig.csv)
    --colors                gene_name/color_code CSV, required with --color-by-gene-name (default: Genes_color_set.csv, set by DEFAULT_COLORS_FILE at the top of the script). If the file is missing the script stops with an error: no silent fallback
    -o, --output            output file; the format follows the extension (.png, .svg, .pdf)
    -r, --reference         reference species shown on top (default: the species with the lowest "phy")
    --highlight             gene_name to highlight
    --color-by-gene-name    color arrows by gene_name instead of annotation
    --spacing               vertical spacing between species (default 0.2)
    --threshold             maximum intergenic distance at real scale, in bp (default 10000)
    --no-flip-strand        do not invert the strand of "R" species (verse already inverted in the CSV)
    --link-skip-missing     link genes across species when the gene is absent in the adjacent one
    --font                  preferred font (fallbacks are applied automatically)
    --no-interactive        never ask questions (pipelines). The questions are also skipped if --highlight or --color-by-gene-name are given, or if the input is not a terminal

The script can also be imported: draw_all_species_loci(df, df_contig, ...) accepts the same parameters as keyword arguments and does not depend on global variables.

MAIN PARAMETERS (draw_all_species_loci):
    - species_reference: reference species shown on top (default None = species with the lowest "phy").
    - distance_threshold_bp: maximum intergenic distance shown at real scale (10000 by default).
    - inter_species_spacing: vertical spacing between species.
    - highlight_gene, highlight_color, highlight_edge, highlight_linewidth: gene highlighting options.
    - color_by_gene_name, gene_colors: coloring options.
    - flip_strand_on_reverse (default True), link_skip_missing (default False).

OUTPUT:
PNG (300 dpi) by default; SVG and PDF are obtained simply by changing the extension of --output. In SVG/PDF the text is kept as editable text (svg.fonttype = none, pdf.fonttype = 42), so the chosen font must be installed on the machine used to open the file.

LIMITATIONS AND ALTERNATIVES:
This script is a drawing utility, not an analysis pipeline. Please keep in mind that:
- It does NOT align sequences and does NOT compute identity: homology groups (gene_name) and identity values must be prepared beforehand by the user. A wrong or inconsistent gene_name produces wrong links, and nothing in the script checks the biology.
- The table preparation is manual (extract_position_gbk.py only helps with coordinates, strand and contig), so it is slower than tools that start directly from GenBank files.
- The figure is static: there is no interactive editing, drag-and-drop reordering or on-the-fly identity filtering. The order of the species is set by the "phy" column.
- Links are drawn only between adjacent species (or the next species carrying the gene with --link-skip-missing); paralogs are paired by order, not by sequence similarity.
- Contig breaks are taken from the contig table prepared by the user, they are not detected from the sequences.
If the script does not give the expected results, or if you need automatic homology detection and interactive figures, we recommend established, peer-reviewed tools such as clinker (https://github.com/gamcil/clinker), which builds the alignments directly from GenBank files and exports editable SVG figures:
    Gilchrist CLM, Chooi Y-H. clinker & clustermap.js: automatic generation of gene cluster comparison figures. Bioinformatics 2021;37(16):2473-2475. DOI: 10.1093/bioinformatics/btab007
